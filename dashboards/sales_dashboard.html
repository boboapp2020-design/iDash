อัปเดตข้อมูลขึ้น Google Sheet

ตั้ง Apps Script ครั้งเดียว แล้วปุ่มอัปเดตจะเขียนลง Sheet ได้เลย (กดดู)
  1. เปิด Google Sheet → Extensions → Apps Script
  2. ลบโค้ดเดิมในไฟล์ Code.gs ทิ้งให้หมด → วางโค้ดข้างล่างนี้ (ID ชีตฝังไว้ให้แล้ว ไม่ต้องแก้อะไร) → กด Save
  3. Deploy → New deployment → กดรูปเฟือง เลือก Web app → Execute as Me → Who has access Anyone → Deploy
  4. ครั้งแรกจะขอ Authorize access → เลือกบัญชี → ถ้าขึ้นเตือน Google hasn't verified ให้กด Advanced → Go to … (unsafe) → Allow
  5. ก็อป Web app URL ที่ลงท้าย /exec มาวางในช่องข้างบน แล้วกด 💾 สแนปช็อต เพื่อฝังค่าไว้ในไฟล์ถาวร
